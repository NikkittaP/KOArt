# Как сайт находят — и что для этого ещё нужно сделать руками

Документ из двух частей: что уже встроено в код (трогать не надо) и что
может сделать только человек с доступом к аккаунтам.

---

## Часть 1. Что уже сделано в коде

| Что | Где живёт | Комментарий |
|---|---|---|
| Meta description на всех страницах | `views/layouts/public.php` + `helpers/Seo.php` | Берётся из текста страницы, с фолбэком на `params['siteDescription']` |
| Canonical URL | `Seo::canonical()` | Отрезает query string, чтобы ссылки с UTM-метками не дробили сигнал |
| hreflang en / ru / x-default | `Seo::alternates()` | `/ru/` — полноценный перевод, а не дубль |
| Open Graph + Twitter Card | layout | Раньше при шеринге был пустой серый прямоугольник |
| Карточки превью 1200×630 | `helpers/OgImage.php` | Генерируются из самой работы, кешируются в `web/og_cache/` |
| sitemap.xml | `controllers/SitemapController.php` | Из базы, с альтернативами по языкам, кеш на час |
| robots.txt | `web/robots.txt` | Указывает на sitemap, закрывает админку |
| schema.org Person / VisualArtwork | `helpers/Schema.php` | **Здесь указано, что художник работает в Мальмё** |
| Аналитика Umami | layout, включается параметром | Без кук, без баннера согласия |

Ключевое для шведской аудитории — последние две строки. В JSON-LD каждой
страницы теперь есть объект `Person` с `PostalAddress` (Malmö, Skåne County,
SE), координатами и ссылками на соцсети. До этого «Malmö, Sweden» было
написано только текстом в подвале — для поисковика это ничего не значило.

## Часть 2. Что нужно сделать руками

Порядок примерно соответствует соотношению «польза / усилия».

### 2.1. Google Search Console — обязательно, 15 минут

Без этого нельзя ни отправить sitemap, ни узнать, по каким запросам сайт
вообще показывается.

1. https://search.google.com/search-console → Add property → **URL prefix** →
   `https://katiaoskina.com`
2. Способ подтверждения — **HTML tag**. Скопировать значение из
   `content="..."` и вписать в `config/params.php`:
   ```php
   'googleSiteVerification' => 'СЮДА_ЗНАЧЕНИЕ',
   ```
   Залить файл на хостинг, нажать Verify.
3. После подтверждения: Sitemaps → добавить `sitemap.xml`.
4. Через неделю-две заглянуть в Performance: там будет видно, по каким
   запросам и из каких стран приходят.

Полезно также добавить свойство для **Domain** (подтверждение через DNS у
Hetzner) — оно объединяет http/https и www/не-www в один отчёт.

### 2.2. Аналитика Umami — 10 минут

1. Завести аккаунт на https://cloud.umami.is (бесплатный тариф).
2. Add website → Domain: `katiaoskina.com`.
3. Settings → Websites → Edit → скопировать **Website ID**.
4. Вписать в `config/params.php`:
   ```php
   'umamiWebsiteId' => 'СЮДА_ID',
   ```
5. Залить файл. Проверить, что счётчик появился:
   ```
   curl -s https://katiaoskina.com/ | grep umami
   ```

Скрипт не подключается локально (dev) и не подключается для залогиненного
владельца — свои заходы в статистику не попадут.

После включения на странице `/privacy` автоматически появится раздел про
аналитику: он выводится только когда ID заполнен.

### 2.3. Bing Webmaster Tools — 10 минут

В Швеции доля Bing заметно выше, чем в среднем по миру (плюс через него
работает поиск в Windows и часть ИИ-ассистентов).
https://www.bing.com/webmasters — там есть импорт прямо из Search Console,
так что это буквально пара кликов после п. 2.1.

### 2.4. Обратные ссылки из соцсетей — 15 минут, высокая отдача

В JSON-LD прописано `sameAs` на Instagram, Behance и LinkedIn. Это работает
в обе стороны только если **в самих профилях стоит ссылка на katiaoskina.com**.
Проверить и при необходимости добавить:

- Instagram → Edit profile → Website
- Behance → Edit profile → Links
- LinkedIn → Contact info → Website

Для поисковика это подтверждение, что профили и сайт принадлежат одному
человеку. Плюс это просто самый реальный источник трафика.

### 2.5. Шведские профессиональные площадки

Это главный рычаг для «чтобы люди из Швеции выходили на сайт»: локальная
выдача сильно зависит от того, ссылаются ли на сайт шведские ресурсы.

Список ниже — **направления для проверки, а не проверенные факты**: условия
членства и наличие каталогов надо уточнить на самих сайтах, они меняются.

| Организация | Почему релевантно |
|---|---|
| **Svenska Tecknare** | Профобъединение иллюстраторов и графических дизайнеров Швеции. Самое прямое попадание в профиль Кати, у них есть каталог участников |
| **KRO (Konstnärernas Riksorganisation)** | Крупнейшая организация художников Швеции |
| **Konstnärscentrum Syd** | Региональное отделение по югу Швеции, то есть по Сконе |
| **Bildupphovsrätt i Sverige** | Общество по авторским правам художников — скорее про роялти, чем про трафик, но профиль там тоже публичный |
| **Form/Design Center (Malmö)** | Городская площадка по дизайну и визуальным искусствам |
| **Malmö Konstförening / Skånes konstförening** | Локальные художественные объединения |

Что важнее самого членства: в каждом таком профиле должна стоять **прямая
ссылка на katiaoskina.com**, а не только email.

### 2.6. Google Business Profile — скорее нет, чем да

Идея напрашивается, но у Google жёсткое требование: профиль положен бизнесу,
который либо имеет адрес, куда приходят клиенты, либо выезжает к клиентам.
Художник, работающий из домашней студии и продающий через интернет, под это,
как правило, не подходит, а профиль с домашним адресом придётся ещё и
публиковать. Имеет смысл возвращаться к этому, только если появится
мастерская, открытая для посетителей, или регулярные занятия/воркшопы с
приходом людей.

Замена, которая работает без этого: связка «schema.org Person с адресом в
Мальмё» (уже сделано) + ссылки со шведских площадок (п. 2.5).

### 2.7. Если захочется шведскую версию сайта

Отдельный большой этап, сознательно не делавшийся сейчас. Технически основа
есть: `codemix/localeurls` уже настроен, языки задаются одной строкой в
`config/web.php`, а `hreflang` и sitemap подхватят третий язык сами.
Упирается не в код, а в контент: нужна миграция БД под колонки `*_sv` и
перевод всех названий работ, описаний серий и биографии — это может сделать
только сам автор.

Практический аргумент против спешки: в Швеции почти вся профессиональная
аудитория свободно читает по-английски, а сайт-портфолио смотрят прежде
всего глазами. Перевод даст прирост в основном на запросах вида
«illustratör Malmö», и браться за него стоит после того, как заработает
Search Console и станет видно, есть ли такие запросы вообще.

## Что проверить через месяц

- Search Console → Performance: появились ли показы по запросам из Швеции
- Umami: откуда идёт трафик, какие работы открывают
- Search Console → Pages: все ли страницы из sitemap проиндексированы
- Search Console → Enhancements: не ругается ли Google на разметку
